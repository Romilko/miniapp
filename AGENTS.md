# miniapp — тренажёр 5000 английских слов

Одностраничное приложение (SPA) без сборки и зависимостей: список блоков слов и
обучение по карточкам (переворот, ответы «Учу»/«Знаю», возврат к предыдущей
карточке, окно английского описания). Деплой — GitHub Pages репозитория
`Romilko/miniapp` (файл `.nojekyll`); коммит в main публикуется сайтом.

## Структура

- `index.html` — единственная страница, вся вёрстка обоих экранов (список
  блоков / обучение) с атрибутами `hidden` для переключения видов.
- `js/app.js` — вся логика в одном IIFE: роутинг, отрисовка, прогресс, события.
  Наверху файла — общий комментарий-обзор приложения, актуализировать при
  изменении поведения.
- `js/data.js` — загрузка и разбор `encards_5500_random_ru.md` в блоки слов
  (fetch в рантайме, формат описан в комментарии файла).
- `css/styles.css` — все стили, секции размечены комментариями.
- `encards_5500_random_ru.md` — источник данных (заголовки «## Блок N …» и
  строки «M. **word** — перевод — описание»). Не редактируется кодом.

## Запуск и проверка

Сборки, тестов и линтеров нет. Локальная проверка — статический сервер:

```sh
python3 -m http.server 8764   # из корня, открыть http://127.0.0.1:8764/
```

Node.js в окружении отсутствует. fetch данных не работает с `file://` — нужен
сервер.

## Архитектура

- Роутинг ручной на History API: `?block=N` — обучение блока N, без параметра —
  список блоков. Клик по любой внутренней ссылке перехватывается глобальным
  слушателем (`preventDefault` + `pushState`); выход из обучения (`data-back`)
  идёт `history.back()`, не новым переходом. Вид приложения не пересоздаёт DOM.
- Прогресс и настройки каждого блока — в localStorage (один ключ
  `PROGRESS_KEY`); приватный режим/недоступный localStorage не должен ломать
  обучение — везде ветки деградации, сохраняйте их при правках.
- Статусы блоков на главной и содержимое карточек восстанавливаются из
  хранилища при загрузке.

## Конвенции

- **Кэш-версии.** Подключения в `index.html` идут с query-версией
  (`styles.css?v=N`, `js/app.js?v=N`, `js/data.js?v=N`, а также `?v=2` в fetch
  внутри `data.js`). Изменили файл — поднимите его версию в `index.html`
  (и в `data.js`, если менялся md), иначе пользователи GitHub Pages увидят
  старую копию из кэша.
- **Стили для тача.** Все `:hover`-правила — только внутри
  `@media (hover: hover)` (на тач-устройствах эмулируемый hover «залипает»);
  отклик при нажатии пальцем — правила `:active`; в `html` задан
  `-webkit-tap-highlight-color: transparent`. Состояние «открыто» у
  кнопок-переключателей (шестерёнка, ⓘ) — через `aria-expanded` + CSS-правило
  `[aria-expanded="true"]`.
- Клавиатурная доступность — через `:focus-visible` (отдельные правила с
  outline); не объединять с `:hover`.
- Комментарии и тексты интерфейса — на русском.
- Новые элементы в `index.html` получать через `document.getElementById`;
  id интерактивных элементов — с префиксом `btn-`.
